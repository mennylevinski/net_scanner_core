# Security Policy

## 🔐 Supported Versions

The following versions of **Net Scanner Core** are supported:

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅ Yes     |
| Older releases | ❌ No      |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### Please **DO NOT**:

* Open a public GitHub issue for security vulnerabilities
* Share exploit details publicly
* Attempt to exploit systems you do not own or have permission to test

### How to report

Please report security issues by:

* Opening a **private security advisory** on GitHub (preferred), or
* Contacting the project maintainer directly: info@secuditor.com

When reporting, include as much detail as possible:

* A clear description of the issue
* Steps to reproduce
* Affected versions
* Potential impact
* Any suggested mitigation (if known)

---

## ⏱️ Response Timeline

The maintainer aims to:

* Acknowledge reports within **72 hours**
* Assess and validate the issue promptly
* Provide a fix or mitigation as soon as reasonably possible

Timelines may vary depending on severity and complexity.
